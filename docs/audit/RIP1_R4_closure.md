  files.** Checked at commit `8c64f54` (the R3 commit): `src/xauusd_swarm/rip1.py` and `scripts/rip1_attacker.py`
  contain 0 occurrences of `chk_key.hex`, `Ed25519PrivateKey.from_private_bytes` or the old
  `sandbox_argv(..., work, view)` signature; `sandbox_argv(..., script, args)` is at line 43 and the per-run
  read-only input dir at line 200. The six files received by the reviewer mixed earlier versions (same file
  names were sent in earlier rounds). Fix of the process: every review bundle now carries a manifest bound to one
  commit (§6).
- R4 also raised substantive hardening points (read-only mounts, termination before reading, untrusted output,
  real break-out attempts, protocol-level reproduction). These were implemented, not argued away.
